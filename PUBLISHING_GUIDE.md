# Riventide Publishing Guide

## Overview
Riventide is a text-based adventure game with rich storytelling, audio, and graphics. This guide covers the best publishing strategies for different platforms.

## Platform Recommendations

### 1. Steam (Primary Platform)
**Why Steam:**
- Large RPG/adventure game audience
- Built-in DRM and update system
- Community features (reviews, forums, achievements)
- Revenue potential: $5-15 per copy

**Requirements:**
- Steam Developer Account ($100 fee)
- Steam SDK integration
- Store page with screenshots, trailer, description
- System requirements documentation

**Pricing Strategy:**
- Launch price: $9.99
- Consider early access at $7.99
- Bundle opportunities with similar games

### 2. Itch.io (Secondary/Testing Platform)
**Why Itch.io:**
- Indie-friendly with 10% revenue share
- No upfront fees
- Great for testing market response
- Flexible pricing (pay-what-you-want option)

**Publishing Steps:**
1. Create Itch.io developer account
2. Upload game files
3. Set pricing (suggested: $5-8)
4. Create store page with screenshots
5. Launch and gather feedback

### 3. GOG (Quality Platform)
**Why GOG:**
- DRM-free approach
- Quality-focused curation
- Good for narrative games
- Higher price point acceptable

**Requirements:**
- Apply through GOG's submission process
- Demonstrate quality and polish
- Provide DRM-free version

## Pre-Publication Checklist

### Technical Preparation
- [ ] Test on Windows, macOS, and Linux
- [ ] Create standalone executables
- [ ] Optimize file sizes
- [ ] Test save/load functionality
- [ ] Ensure all assets are properly licensed

### Marketing Materials
- [ ] Game trailer (2-3 minutes)
- [ ] Screenshots (10-15 high-quality images)
- [ ] Game description (500-1000 words)
- [ ] System requirements
- [ ] Press kit with logos and assets

### Legal Requirements
- [ ] Review all asset licenses
- [ ] Create privacy policy
- [ ] Terms of service
- [ ] EULA (End User License Agreement)

## Packaging Options

### Option 1: Python Executable
```bash
# Using PyInstaller
pip install pyinstaller
pyinstaller --onefile --windowed main.py
```

### Option 2: Steam Integration
- Use Steam's SDK for achievements and cloud saves
- Implement Steam Workshop for mods (future feature)
- Add Steam trading cards

### Option 3: Cross-Platform Distribution
- Windows: .exe installer
- macOS: .dmg file or App Store
- Linux: .deb/.rpm packages or Snap

## Marketing Strategy

### Pre-Launch
1. **Build Community:**
   - Create Discord server
   - Start Twitter/X account
   - Engage with RPG communities

2. **Press Outreach:**
   - Contact indie game reviewers
   - Submit to gaming websites
   - Reach out to YouTubers/streamers

3. **Demo Release:**
   - Release free demo on Itch.io
   - Gather feedback and testimonials
   - Build email list

### Launch Strategy
1. **Steam Launch:**
   - Coordinate with Steam's algorithm
   - Use Steam's visibility features
   - Engage with Steam community

2. **Cross-Platform Release:**
   - Launch on multiple platforms simultaneously
   - Use platform-specific features
   - Monitor performance across platforms

## Revenue Optimization

### Pricing Strategy
- **Itch.io:** $5-8 (pay-what-you-want option)
- **Steam:** $9.99 (with sales down to $4.99)
- **GOG:** $9.99 (DRM-free premium)

### Sales and Bundles
- Participate in Steam sales (Summer, Winter, etc.)
- Bundle with similar games
- Offer soundtrack as DLC

### Post-Launch Content
- Additional story branches
- New character classes
- Soundtrack release
- Art book

## Technical Requirements

### Minimum System Requirements
- **OS:** Windows 7+, macOS 10.12+, Ubuntu 16.04+
- **Processor:** 1.5 GHz dual-core
- **Memory:** 2 GB RAM
- **Graphics:** Any modern graphics card
- **Storage:** 500 MB available space
- **Audio:** DirectX compatible sound card

### Recommended System Requirements
- **OS:** Windows 10+, macOS 10.15+, Ubuntu 18.04+
- **Processor:** 2.0 GHz quad-core
- **Memory:** 4 GB RAM
- **Graphics:** Integrated graphics or better
- **Storage:** 1 GB available space
- **Audio:** High-quality audio output
